JAVASCRIPT BUTTON.

Goal: click a button and change a message. This is a simple way to make a webpage interactive.

lesson.js● LIVE
// 1. Find the message
const message = document
  .getElementById("message");

// 2. Change the text on click
function sayHello() {
  message.textContent =
    "Hello, future developer!";
}
PREVIEW / READY

Click the button below ↓

Waiting for your click...

How does it work? First, getElementById finds the message. Then, the function changes its text when you click. The expected result is “Hello, future developer!”

Common mistake: Check the spelling of message. The name must be the same in HTML and JavaScript.
